## 6. データモデル
```
AppState
├─ boards: Record<boardId, Board>
├─ boardOrder: boardId[]
└─ activeBoardId: string | null

Board
├─ id, title
├─ lists: Record<listId, List>
├─ listOrder: listId[]
├─ cards: Record<cardId, Card>
└─ labels: Record<labelId, Label>

List: { id, title, cardIds: cardId[] }
Card: { id, title, description?, labelIds: labelId[], dueDate? }
Label: { id, name, color }
```

### 7.1 サイドバー（左固定）
- ボード一覧を縦に表示し、選択中のボードをハイライト表示する
- 各ボード名の右に削除ボタン（×）を配置する
- 下部に「新しいボード名」の入力欄と追加ボタンを配置する

### 7.2 ボード画面（メイン領域）
- **ツールバー**: ボードタイトル（クリックで編集可）と検索バーを左右に配置する
- **リスト一覧**: 横スクロールで複数のリストを並べる。各リストはドラッグで並び替え可能
- **リスト内**:
  - リストタイトル（クリックで編集可）と削除ボタン
  - カードを縦に並べたカードリスト（ドラッグで並び替え・リスト間移動可能）
  - 下部に「+ カードを追加」ボタン
- **リスト追加**: リスト一覧の右端に「+ リストを追加」ボタンを常設する

### 7.3 カード表示（リスト内のカード1枚）
- ラベルバッジ（複数、色付き）をカード上部に表示する
- カードタイトルを表示する
- 期限バッジを下部に表示し、状態に応じて色分けする
  - 通常（期限が先の日付）: グレー表示
  - **本日締切**: オレンジ色で強調表示し、「本日締切」であることが一目でわかるようにする（未実装・今後対応）
  - 期限超過（過去の日付）: 赤色で強調表示する

### 7.4 カード詳細モーダル
- カードクリック時にオーバーレイ表示される
- タイトル入力欄（インライン編集）
- 説明欄（複数行テキスト）
- 期限日入力欄（date input）
- ラベル選択欄（ボードのラベル一覧から複数選択、新規ラベル作成も可能）
- 下部に削除ボタンと保存/キャンセルボタンを配置する
