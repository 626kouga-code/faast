## 4. 非機能要件

### 4.1 技術スタック
| 区分 | 内容 |
|---|---|
| フロントエンド言語/フレームワーク | React + TypeScript（Next.jsは対象外） |
| フロントエンドビルドツール | Vite |
| フロントエンドHTTPクライアント | Axios |
| バックエンド言語/フレームワーク | Java 21 + Spring Boot 3 |
| バックエンドビルドツール | Maven |
| API方式 | REST API（JSON） |
| O/Rマッパー | Spring Data JPA（Hibernate） |
| データベース | PostgreSQL |
| マイグレーション管理 | Flyway |
| バックエンドテスト | JUnit 5 + Mockito |
| フロントエンドテスト | Vitest + React Testing Library |

### 4.2 その他非機能要件
| 項目 | 内容 |
|---|---|
| データ永続化 | PostgreSQL（バックエンドAPI経由でCRUD操作を行う） |
| 対応環境 | Google Chrome / Microsoft Edge の最新2バージョン |
| 画面サイズ対応 | PC向けレイアウトのみ対応。スマートフォン等の小画面には最適化しない |
| 起動速度 | ローカル環境で初回表示3秒以内を目安とする |
| 認証 | なし（単一利用者・単一ブラウザ前提） |
| オフライン動作 | 不可（バックエンドAPI・PostgreSQLとの通信が必須） |

## 5. 機能要件

### 5.1 ボード管理
- ボードを複数作成できる
- サイドバーにボード一覧を表示し、クリックで切り替えられる
- ボードのタイトルは作成時に指定し、後から名前をクリックして変更できる
- ボードを削除できる（確認ダイアログあり）

### 5.2 リスト管理
- 選択中のボード内にリスト（列）を複数作成できる
- リストのタイトルはクリックしてインライン編集できる
- リストを削除できる（配下のカードも削除される、確認ダイアログあり）
- リスト同士はドラッグ&ドロップで順序を入れ替えられる

### 5.3 カード管理
- リスト内にカードを作成できる（タイトル必須）
- カードをクリックすると詳細モーダルが開く
- カード詳細では以下を編集できる
  - タイトル
  - 説明（複数行テキスト）
  - 期限日（date input）
  - ラベル（複数選択可）
- カードを削除できる（確認ダイアログあり）
- カードはドラッグ&ドロップで同一リスト内の並び替え、および別リストへの移動ができる

### 5.4 ラベル管理
- ボードごとにラベルを作成できる（名前＋色を指定）
- カード編集画面からラベルの割り当て・解除ができる
- ラベルを削除すると、割り当てられていたカードからも自動的に外れる
- カード表面に割り当てられたラベルが色付きバッジとして表示される

### 5.5 期限管理
- カードに期限日を設定できる
- カード表面に「期限: YYYY-MM-DD」の形式で期限が表示される
- 期限日が過去の場合、赤字で強調表示される（期限超過の視覚的通知）

### 5.6 検索
- ボード上部の検索バーにキーワードを入力すると、タイトル・説明にマッチするカードのみが表示される
- 検索対象は現在表示中のボードに限る

### 5.7 データ永続化
- ボード・リスト・カード・ラベルの全状態はバックエンドAPI経由でPostgreSQLに保存される
- ページを再読み込みしてもAPIからデータを再取得して状態が復元される
- 初回起動時はサンプルボード（Todo/Doing/Doneの3リスト、サンプルカード、ラベル3種）が自動生成される
