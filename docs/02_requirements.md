### 4.2 その他非機能要件


| 項目      | 内容                                       |
| ------- | ---------------------------------------- |
| データ永続化  | カードのみPostgreSQL（バックエンドAPI経由でCRUD操作）。ボード/リスト/ラベルはlocalStorage |
| 対応環境    | Google Chrome / Microsoft Edge の最新2バージョン |
| 画面サイズ対応 | PC向けレイアウトのみ対応。スマートフォン等の小画面には最適化しない       |
| 起動速度    | ローカル環境で初回表示3秒以内を目安とする                    |
| 認証      | あり（メールアドレス＋パスワードによるユーザー登録・ログイン、セッションCookie方式） |
| オフライン動作 | 不可（バックエンドAPI・PostgreSQLとの通信が必須）          |


## 5. 機能要件

### 5.1 ボード管理

- ボードを複数作成できる
- サイドバーにボード一覧を表示し、クリックで切り替えられる
- ボードのタイトルは作成時に指定し、後から名前をクリックして変更できる
- ボードを削除できる（確認ダイアログあり）

### 5.2 リスト管理

- 選択中のボード内にリスト（列）を複数作成できる
- リストのタイトルはクリックしてインライン編集できる
- リストを削除できる（配下のカードも削除される、確認ダイアログあり）
- リスト同士はドラッグ&ドロップで順序を入れ替えられる

### 5.3 カード管理

- リスト内にカードを作成できる（タイトル必須）
- カードをクリックすると詳細モーダルが開く
- カード詳細では以下を編集できる
  - タイトル
  - 説明（複数行テキスト）
  - 期限日（date input）
  - 優先度（高・中・低、未設定可）
  - ラベル（複数選択可）
- カードを削除できる（確認ダイアログあり）
- カードはドラッグ&ドロップで同一リスト内の並び替え、および別リストへの移動ができる

### 5.4 ラベル管理

- ボードごとにラベルを作成できる（名前＋色を指定）
- カード編集画面からラベルの割り当て・解除ができる
- ラベルを削除すると、割り当てられていたカードからも自動的に外れる
- カード表面に割り当てられたラベルが色付きバッジとして表示される

### 5.5 期限管理

- カードに期限日を設定できる
- カード表面に「期限: YYYY-MM-DD」の形式で期限が表示される
- 期限日が過去の場合、赤字で強調表示される（期限超過の視覚的通知）

### 5.6 検索

- ボード上部の検索バーにキーワードを入力すると、タイトル・説明にマッチするカードのみが表示される
- 検索対象は現在表示中のボードに限る

### 5.7 ユーザー登録・ログイン

- メールアドレス・ユーザー名・パスワードを入力してユーザーアカウントを新規登録できる
- メールアドレスは一意（重複登録不可）で、パスワードはBCryptでハッシュ化してPostgreSQLに保存される
- 登録済みのメールアドレス・パスワードでログインできる（セッションCookie方式でログイン状態を維持）
- ログアウトできる
- 未ログイン時はログイン/新規登録画面が表示され、ボード画面にはアクセスできない
- アクセス制御（ボード・カード単位の権限管理）は対象外（別Issueで対応）

### 5.8 データ永続化

- **カード**（タイトル・説明・期限・所属リスト・並び順）はバックエンドAPI経由でPostgreSQLに保存される。ページを再読み込みするとAPIから再取得され、常に最新の状態が復元される
- **ボード・リスト・ラベル・カードへのラベル割り当て**はブラウザのlocalStorageに保存される（バックエンドにはボード/リストのテーブルが無いため）
- 初回起動時はサンプルボード（Todo/Doing/Doneの3リスト、ラベル3種）が自動生成される。ボード/リストにはバックエンドのカードと紐付けるための数値ID（`backendId`）が採番される
