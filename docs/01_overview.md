# 概要・目的・対象ユーザー

## 1. 概要
Trello風のカンバンボードによるタスク管理アプリ。React製フロントエンドとJava/Spring Bootバックエンドで構成され、データはPostgreSQLに保存する個人向けタスク管理ツール。

日々のタスクを「Todo / Doing / Done」のようなリストに分け、カードとしてタスクを書き出し、進捗に応じてドラッグで移動させながら管理することを主な利用シーンとして想定する。会員登録やインストールなしに、ブラウザを開けばすぐ使い始められる手軽さを重視する。

## 2. 目的
- 毎日のタスクを一覧化し、抜け漏れなく管理できるようにする
- タスクの状態（未着手・作業中・完了）をボード上の位置で直感的に把握できるようにする
- 期限やラベルを使って、その日・その週にやるべきことの優先度を視覚的に区別できるようにする
- ボード/リスト/カードの階層構造による柔軟なタスク整理

## 3. 対象ユーザー
- 個人で日々のタスクを管理したい利用者
- マルチユーザー・アカウント機能は持たず、単一利用者・単一ブラウザでの利用を前提とする
